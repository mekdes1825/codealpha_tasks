# Task 2: Phishing Awareness Training

## 📌 Project Overview

This project is part of the CodeAlpha Cybersecurity Internship.

The goal is to educate users about phishing attacks, help them recognize suspicious messages, and encourage safer online behavior.

The project includes a PowerPoint training presentation and an interactive 10-question quiz with scenario-based questions, explanations, and a final score.

---

## 🎯 Objectives

- Understand what phishing is and how it works.
- Recognize common phishing techniques and warning signs.
- Learn how to respond safely to suspicious messages.
- Test phishing awareness through an interactive quiz.
