# Task 2: Phishing Awareness Training

## 📌 Project Overview

This project was developed as part of the CodeAlpha Cybersecurity Internship.

It aims to help users recognize phishing attacks, identify suspicious messages, and practice safer online behavior.

The project includes a PowerPoint training presentation and an interactive quiz with 10 scenario-based questions.

---

## 🎯 Objectives

- Understand phishing and common attack techniques.
- Recognize suspicious messages, links, and websites.
- Learn how to verify requests safely.
- Practice responding to phishing attempts.
